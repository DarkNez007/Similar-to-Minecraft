Проект представляет собой реализацию воксельной игры (клон Minecraft) с нуля на языке Rust. Рендеринг выполняется через Bevy с принудительным использованием Vulkan backend'а, что обеспечивает максимальную производительность и контроль над графическим конвейером. Мир генерируется процедурно с использованием шума Перлина, имитируя генерацию ландшафта из оригинального Minecraft.

✨ Возможности
🎮 Управление персонажем
Ходьба и бег — перемещение по миру на WASD

Прыжки — физика прыжка с гравитацией

Полёт — режим креативного полёта (двойное нажатие Space)

Коллизии AABB — корректное взаимодействие игрока с блоками (антитуннелирование через подшаги)

Свободная камера — обзор от первого лица с захватом курсора

🧱 Рендеринг
Vulkan API — принудительное использование Vulkan через WgpuSettings { backends: Some(Backends::VULKAN) }

Рендеринг блоков — отрисовка воксельных чанков 16×128×16

Отсечение невидимых граней — face culling для экономии ресурсов (невидимые соседние грани не генерируются)

Группировка по текстурам — один меш на каждый тип текстуры в чанке

Прозрачность — поддержка AlphaMode::Mask для листвы

Освещение — DirectionalLight + AmbientLight

🌍 Процедурная генерация
Шум Перлина — двухслойная генерация рельефа (базовый + детальный), схожая с Minecraft

Два типа мира — Normal (холмистый) и Flat (плоский)

Сид мира — детерминированная генерация по числовому seed'у

Деревья — процедурная расстановка дубов (ствол + листва в форме кроны) через хеш-функцию

Чанки — загрузка области вокруг спавна (радиус 3 чанка)

🖥️ Интерфейс
Главное меню — Single Player / Settings / Quit

Создание мира — ввод seed'а с клавиатуры, выбор типа мира, случайный seed

Меню паузы — Resume / Main Menu (с полной очисткой мира)

Perf UI — оверлей с FPS, временем кадра и количеством сущностей (iyes_perf_ui)

🛠️ Требования
Rust 1.98.1 или новее (rustup.rs)

Vulkan SDK версии 1.3+ (vulkan.lunarg.com)

GPU с поддержкой Vulkan

ОС: Windows 10+, Linux, macOS (через MoltenVK)

🚀 Сборка и запуск
bash
# Клонирование репозитория
git clone https://github.com/your-username/mc-rust.git
cd mc-rust

# Сборка в режиме release (рекомендуется для производительности)
cargo build --release

# Запуск
cargo run --release
💡 Для максимальной производительности в Cargo.toml уже настроены codegen-units = 1, lto = "thin" и opt-level = 3.

🏗️ Архитектура
Типы блоков
Поддерживаются блоки: Air, Grass, Stone, OakLog, OakLeaves. Каждый блок имеет набор текстур для разных граней (например, трава имеет отдельные текстуры для верха, низа и боков).

Меширование чанков
Чанк — это куб 16×128×16 блоков. Грани генерируются только на границе с прозрачными блоками (air или leaves), что даёт значительную экономию полигонов. Грани группируются по типу текстуры, для каждой группы создаётся отдельный Mesh и назначается StandardMaterial.

Коллизии игрока
AABB игрока (0.6 × 1.8) проверяется по трём осям раздельно. Движение разбивается на подшаги MAX_STEP = 0.2, чтобы избежать туннелирования сквозь тонкие препятствия на высокой скорости.

Процедурная генерация
Высота поверхности вычисляется как комбинация двух слоёв шума Перлина:

text
h = BASE_HEIGHT + (perlin_coarse * 0.75 + perlin_detail * 0.25) * 18
Деревья расставляются детерминированно по хешу от (seed, x, z) — примерно 1 дерево на 120 колонок.
